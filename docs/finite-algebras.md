# Finite coefficient fields and quotient algebras

## When to use these operations

Many algebraic questions concern the **structure** of solutions, not their numerical locations. A finite-dimensional quotient algebra records solutions together with multiplicities and nilpotent directions. Its nilradical detects nonreduced structure, its reduced quotient discards nilpotents, and its primary decomposition separates local factors. Over finite fields, the Frobenius map supplies exact linear algebra in cases where trace pairings cannot detect nilpotence.

These operations apply to zero-dimensional quotient algebras over supported exact coefficient fields. They do not solve arbitrary positive-dimensional polynomial ideals, and they are not interchangeable with the complex numerical root solvers.

## Constructing finite fields

`algroots.finite_fields.finite_field(p, degree)` creates `GF(p)` when `degree=1` and a finite extension of cardinality `p**degree` otherwise. The characteristic `p` must be prime. An explicit irreducible polynomial can select the extension representation. Use `field_elements` to enumerate every element, `field_order` for the cardinality, and `factor_univariate` to factor a univariate `Poly` over its declared finite coefficient domain.

```python
import sympy as sp
from algroots.finite_fields import field_elements, field_order, finite_field, factor_univariate

x = sp.Symbol("x")
field = finite_field(2, 2)
assert field_order(field) == 4
assert len(set(field_elements(field))) == 4

polynomial = sp.Poly(x**4 - x, x, domain=field)
unit, factors = factor_univariate(polynomial)
rebuilt = sp.Poly(unit, x, domain=field)
for factor, multiplicity in factors:
    rebuilt *= factor**multiplicity
assert rebuilt == polynomial
```

Finite extension fields use exact arithmetic backed by python-flint. `factor_univariate` factors the specified polynomial; it does not infer a coefficient field from floating-point input.

## Nilpotents, reduced quotients, and primary factors

For an ideal $I\subseteq K[x_1,\ldots,x_n]$ whose quotient $A=K[x_1,\ldots,x_n]/I$ is finite-dimensional, the nilradical is $\sqrt{0}=\{a\in A:a^m=0\text{ for some }m>0\}$. The **reduced algebra** is $A/\sqrt{0}$. Primary decomposition splits the finite algebra into local factors, retaining their nilpotent structure.

In characteristic zero, the trace pairing $(a,b)\mapsto\operatorname{Tr}(ab)$ detects the nilradical. In characteristic $p$, that pairing can vanish for reasons unrelated to nilpotence. Over $\mathrm{GF}(q)$, `frobenius_matrix(algebra)` represents the $q$-power Frobenius map on the quotient algebra in the standard-monomial basis. This map is $\mathrm{GF}(q)$-linear, and sufficiently high powers detect nilpotent directions.

```python
import sympy as sp
from algroots.finite_decomposition import (
    frobenius_matrix,
    nilradical_basis,
    primary_decomposition,
    reduced_algebra,
)
from algroots.quotient import QuotientAlgebra

x = sp.Symbol("x")
algebra = QuotientAlgebra.from_polynomials((x**2,), (x,), domain=sp.GF(2))
assert algebra.dimension == 2
assert len(nilradical_basis(algebra)) == 1
assert frobenius_matrix(algebra).to_Matrix() == sp.diag(1, 0)
assert reduced_algebra(algebra).dimension == 1

((component, residue),) = primary_decomposition(algebra)
assert component.dimension == 2
assert residue.dimension == 1
assert residue.is_field
```

The returned pairs are `(primary_factor_algebra, residue_field)`. These are quotient-algebra objects, not just a list of geometric points. Their dimensions account for multiplicities.

## Why nonmonogenic algebras matter

A quotient need not be generated by a single element over its coefficient field. For instance, over $\mathrm{GF}(2)$, the equations $x^2-x=y^2-y=0$ define the product of four copies of $\mathrm{GF}(2)$. It has four factors even though the base field has only two elements. The finite-algebra decomposition algorithm splits via Frobenius-fixed elements and does not require a separating element with four distinct values in $\mathrm{GF}(2)$.

```python
import sympy as sp
from algroots.finite_decomposition import primary_decomposition
from algroots.quotient import QuotientAlgebra

x, y = sp.symbols("x y")
algebra = QuotientAlgebra.from_polynomials((x**2 - x, y**2 - y), (x, y), domain=sp.GF(2))
factors = primary_decomposition(algebra)
assert len(factors) == 4
assert sum(component.dimension for component, _ in factors) == algebra.dimension
assert all(component.dimension == residue.dimension == 1 for component, residue in factors)
```

## Exact characteristic-zero algebras

The same `nilradical_basis`, `reduced_algebra`, and `primary_decomposition` interfaces handle finite quotients over supported characteristic-zero domains. The characteristic-zero primary-decomposition routine searches for a separating linear form with a user-set `max_separating_attempts` budget; its result is still exact when it succeeds. Rational-function coefficient domains are also supported in the finite quotient API, with explicit parameters. See [Quotient Tools](quotient-tools.md) for constructing and specializing such quotients.

## Boundaries and failure semantics

- The input must be a `QuotientAlgebra` of finite dimension; a positive-dimensional ideal has no finite staircase for these methods.
- Characteristic-zero and **finite perfect** coefficient fields are supported for nilradicals and primary factors. A rational-function field of characteristic $p$, such as `GF(2)(t)`, is not a finite field and is rejected by these operations.
- The finite-field Frobenius map is exact; it does not certify complex numerical root locations. Conversely, Arb-based complex root extraction is not a finite-field solver.
- A primary decomposition of a finite algebra is not a general primary decomposition of a positive-dimensional ideal, nor a computation of its local dual bases.
